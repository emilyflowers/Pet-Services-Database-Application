# Pet-Services-Database-Application
## Authors: 
Emily Flowers, Jacob Markward, Natalia Mar Morales, Chase Harrison

## About: 
This project was created as a group project for Database Systems. Our project creates a Web Application which can be used by a company that provides services for pets, such as boarding, grooming, and training. The front-end of our application uses HTML and CSS. Our DBMS is mySQL, and PHP is used to link any front-end actions to our database on the back-end. This project is designed to be run using XAMPP which provides a local host for the database.
